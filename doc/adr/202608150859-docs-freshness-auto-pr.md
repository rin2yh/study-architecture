# ADR-202608150859: ドキュメント鮮度を決定的レーンと AI レーンの自動 draft PR で維持する

- Status: Accepted
- Date: 2026-08-15
- Relates to: ADR-[[202607020343]] (CI で構造を弾く枠。本 ADR は弾けないズレを直す枠), ADR-[[202606210900]] (意味判定を LLM へ委譲する先例), ADR-[[202606170901]] (生成で単一情報源に寄せる)

## Context

- ドキュメントの更新は人手の不定期棚卸しに依存しており、`README.md` / `doc/ops/**` は最終更新から
  実装側に 41〜49 コミット、`client/app/ui/README.md` は 101 コミットの差が開いていた。
- 実測した陳腐化: サービス表がコンテナ内ポート・inventory・ワーカーを取り違えたまま、フロントエンドの
  記述が Superseded 済みの TanStack Start のまま、実在しない ADR 参照が 2 件。
- 一方 `doc/adr/README.md` だけは追随できている。`.claude/rules/adr.md` が一覧更新を作業手順に
  埋め込んでいるためで、手順や機械に埋めた箇所しか保たれていない。
- ADR-[[202607020343]] の fitness function は「違反を弾く」枠であり、開いてしまった差を「直す」経路は無い。

## Decision

ドキュメントの鮮度維持を **2 レーンに分け、どちらも draft PR で人のレビューを必ず挟む**。

- **決定的レーン**: 参照リンク検査 (`scripts/docs/lint-refs.sh`) と compose.yaml からのサービス表生成
  (`scripts/docs/gen-service-table.sh`)。PR CI で hard fail し、定期実行では自動 PR を出す。
  → 一意に直せるものを LLM に渡さない。差分が安定しレビューが要らなくなる。
- **AI レーン**: 散文のズレを antigravity CLI (`agy`) に委譲する (`scripts/docs/agent-fix.sh`)。
  入力は「対象ドキュメントの最終更新以降に変わった実装」に絞り、1 実行 1 ドキュメントに閉じる。
  → 差分を小さく保ち、レビュー可能性と実行コストを両立させる。
- **AI の書き込み範囲を機械で縛る**: 書き換えてよいのは対象ドキュメント 1 本のみ。範囲外を触ったら
  その場で破棄して job を落とす。`doc/adr/**` の新規作成と Status 変更は禁止し、設計判断は人が起こす。
- **成否を終了コードで判定しない**: headless の `agy` は承認を得られないツールを soft-deny して exit 0 で
  素通りするため、`git diff` を唯一の判定材料にする。
- **CLI を交換可能にする**: 呼び出しは `DOCS_AGENT_CMD` 越しのラッパー 1 枚に閉じ、CLI ごと差し替えられる
  ようにする。認証は `GEMINI_API_KEY` を GitHub Secrets に置く。

## Consequences

- ドキュメントの陳腐化が検出されないまま溜まる状態が終わり、生成に寄せた表は構造的に腐らなくなる。
- 外部 AI サービスへの依存が CI の**書き込み**経路に入る。draft PR + 書き込みパス制限 + ADR 禁止で
  信頼境界を保つが、レビュー無しのマージは前提から外れる。
- `agy` の headless 認証は 2026-08-14 に入ったばかりで、CI 用の API キー認証を求める upstream issue も
  open のまま。AI レーンは当面 `workflow_dispatch` 限定とし、実測後に `schedule` へ昇格させる。
- 生成物のマーカーを壊すと生成が失敗する。README の該当範囲は手編集できなくなる。

## Alternatives considered

- **決定的レーンだけにする**: 外部依存ゼロで確実だが、散文のズレ (フレームワーク名・処理の流れ) は
  誰かが気づくまで残る。今回の陳腐化の大半がそこにあり、放置すると同じ状態に戻る。
- **全部を AI に投げる**: 実装は単純だが、決定的レーンで得られる差分の安定性を捨てることになる。
- **自動 PR を作らず issue で報告する**: 気づきは供給できるが直す動機が続かず形骸化する。
  ADR-[[202607020343]] が warn 運用を退けたのと同じ理由。
- **Claude Code Action を使う**: 公式 action があり導入は軽いが、CLI 選定は利用者の意向で決まる。
